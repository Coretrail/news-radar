Erro 403 · Acesso restrito

Esta ligação não tem acesso ao Radar.

O Notícias Radar é um serviço privado. O endereço de origem da sua ligação não está autorizado a aceder a este servidor.

Como pode resolver

  1. Confirme que está ligado à rede autorizada para utilizar o Radar.
  2. Se estiver a usar dados móveis, outra rede Wi-Fi ou uma VPN, verifique se essa ligação tem acesso autorizado.
  3. Se já estiver na rede correta, contacte o administrador para verificar a autorização do seu endereço IP. Indique que recebeu o erro 403.

Iniciar sessão na administração não resolve esta restrição: o acesso é verificado pela rede antes de abrir a aplicação.
